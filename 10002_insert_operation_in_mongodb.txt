when to use Special characters:
*(special characters): If a field name contains special characters or spaces,
                       or starts with a numeric digit, using quotes is necessary
*(reserved words): If a field name is a reserved keyword in MongoDB, 
                   use quotes to distinguish it from the reerved keyword

case sensitivity in MongoDB
* collection names are case-sensitive.
* field names within documents are case-sensitive.
